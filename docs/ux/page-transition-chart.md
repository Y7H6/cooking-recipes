# ⭐ 6. 完全版 画面遷移図（UXフロー）


---

# **B. 既存レシピ検索 → レーダーチャート表示 → 編集フロー**

```
トップページ
   │
   ▼
既存レシピ検索（/recipes/search）
   │  ・保存済みレシピも検索対象
   │  ・各レシピに「味のレーダーチャート」を表示
   │
   ▼
レシピ詳細（/recipes/edit/[id]）
   │  ・材料追加・削除・分量変更
   │  ・Jevで味スコア再評価
   │  ・レーダーチャート表示（初期状態）
   │
   ▼
レシピ保存（DB）
```

### 🔥 **ここで新要件を満たすポイント**
- **保存したレシピは検索画面に表示される**  
- **検索画面でレーダーチャートを一緒に表示する**  
- **ユーザーは「味の傾向」を見てレシピを選べる**

---

# **C. Qwen補助 → 編集 → レーダーチャート比較フロー**

```
レシピ編集ページ（/recipes/edit/[id]）
   │
   ├── [Qwenで改善案を生成する]
   │         │
   │         ▼
   │   Qwen生成レシピ（/recipes/assist?base=id）
   │         │
   │         ▼
   │   編集ページ（/recipes/edit/[new_id]）
   │         │
   │         ▼
   │   Jevで再評価
   │         │
   │         ▼
   │   レーダーチャート比較（初期レシピ vs 改善レシピ）
   │
   ▼
保存
```

### 🔥 **ここで新要件を満たすポイント**
- **初期レシピのレーダーチャートを保持する**  
- **Qwen生成レシピのレーダーチャートと比較する**  
- **味の変化（甘味・辛味・旨味など）が視覚的にわかる**

---

# **D. 材料からレシピ作成（Qwen補助） → 編集 → 比較フロー**

```
トップページ
```

### 🔥 新要件対応

- **編集後の味の変化をレーダーチャートで表示**

---

# **E. バルク生成（最大10レシピ）→ 一括評価 → レーダーチャート比較フロー**

```
トップページ
   │
   ▼
バルク生成（最大10レシピ、/recipes/bulk）
   │
   ▼
Jev一括評価（/recipes/evaluate_bulk）
   │
   ▼
ランキング表示（/recipes/bulk/[batch_id]/ranking）
   │
   ▼
レーダーチャート比較（/recipes/compare）
```

### 🔥 新要件対応
- **初期レシピのレーダーチャートを基準にして比較できる**  
- **Qwenの自動生成による味の変化を視覚化できる**

---

# **F. 保存されたレシピの扱い（新要件）**

### 保存されたレシピは以下の画面で利用される：

| 画面 | 保存レシピの利用方法 |
|------|------------------------|
| `/recipes/search` | レシピ一覧＋レーダーチャート表示 |
| `/recipes/edit/[id]` | 編集可能（追加・削除・分量変更） |
| `/recipes/compare` | 初期レシピ vs 改善レシピ vs 自動生成レシピ |
| `/recipes/bulk/[batch_id]/ranking` | 自動生成レシピとの比較 |

---

# **G. レーダーチャートの役割（新要件の中心）**

### レーダーチャートは常に以下を表示できる：

- **初期レシピの味覚スコア**  
- **編集後レシピの味覚スコア**  
- **Qwen改善案の味覚スコア**  
- **10レシピ自動生成の代表レシピの味覚スコア**

### これにより：

- **味の変化が一目でわかる**  
- **ユーザーが操作した結果がどう味に影響したか理解できる**  
- **AIによる自動生成の味の傾向がわかる**
