# **5. Next.js 画面モックアップ案（UI/UX）**

以下は **全機能をカバーする画面構成**です。

---

# **画面一覧（全体構成）**

1. **トップページ（/）**  
2. **既存レシピ検索ページ（/recipes/search）**  
3. **レシピ編集ページ（/recipes/edit/[id]）**  
4. **Qwen補助レシピ生成ページ（/recipes/assist）**  
5. **100レシピ自動生成ダッシュボード（/recipes/bulk）**  
6. **レーダーチャート比較ページ（/recipes/compare）**

---

# **1. トップページ（/）**

### 目的  
ユーザーが目的の機能に最短でアクセスできるようにする。

### モックアップ（テキストワイヤー）
```
-----------------------------------------------------
| 味覚AIエンジン PoC                                 |
-----------------------------------------------------
| [既存レシピから始める]                              |
| [材料からレシピを作る（Qwen補助）]                  |
| [100レシピ自動生成で味覚探索]                       |
-----------------------------------------------------
```

---

# **2. 既存レシピ検索ページ（/recipes/search）**

### 機能  
- ジャンル選択  
- キーワード検索  
- レシピ一覧表示  
- 選択したレシピを編集ページへ

### モックアップ
```
-----------------------------------------------------
| ジャンル: [和食 ▼] [中華 ▼] [洋食 ▼] [スイーツ ▼] |
| キーワード: [カレー] (検索ボタン)                  |
-----------------------------------------------------
| 検索結果:                                          |
| -------------------------------------------------- |
| 和風カレー（ID:101）   [編集する]                  |
| 鶏肉の照り焼き（ID:102） [編集する]                |
| ...                                                |
-----------------------------------------------------
```

---

# **3. レシピ編集ページ（/recipes/edit/[id]）**

### 機能  
- 材料追加  
- 材料削除  
- 分量変更  
- Jevで味スコア再評価  
- レーダーチャート表示  
- Qwenによる改善案生成

### モックアップ
```
-----------------------------------------------------
| レシピ名: 和風カレー                               |
-----------------------------------------------------
| 材料リスト                                         |
| -------------------------------------------------- |
| 鶏肉      [200g]   [-削除]                         |
| 玉ねぎ    [100g]   [-削除]                         |
| 醤油      [20ml]   [-削除]                         |
| 砂糖      [15g]    [-削除]                         |
| 唐辛子    [2g]     [-削除]                         |
| -------------------------------------------------- |
| [+ 材料を追加]                                     |
-----------------------------------------------------
| 作り方（テキストエリア）                           |
-----------------------------------------------------
| [味スコアを計算する（Jev）]                         |
-----------------------------------------------------
| レーダーチャート表示                               |
| （甘さ・辛さ・旨味・塩味・苦味・総合）             |
-----------------------------------------------------
| [Qwenで改善案を生成する]                           |
-----------------------------------------------------
```

---

# **4. Qwen補助レシピ生成ページ（/recipes/assist）**

### 機能  
- 材料入力  
- 条件入力（和食風・辛さ控えめなど）  
- Qwen生成レシピを編集ページへ展開

### モックアップ
```
-----------------------------------------------------
| 材料: [鶏肉, 玉ねぎ, 醤油, 砂糖]                   |
| 条件:                                              |
|   料理スタイル: [和食 ▼]                           |
|   辛さレベル:   [控えめ ▼]                         |
|   調理時間:     [30分以内 ▼]                       |
-----------------------------------------------------
| [Qwenでレシピを生成する]                           |
-----------------------------------------------------
| 生成結果:                                          |
| -------------------------------------------------- |
| タイトル: 和風鶏肉煮込み                           |
| 材料:                                              |
|   鶏肉 200g                                        |
|   玉ねぎ 100g                                      |
|   醤油 20ml                                        |
|   みりん 10ml                                      |
| 作り方:                                            |
|   鶏肉と玉ねぎを炒め、醤油とみりんで煮込む。       |
-----------------------------------------------------
| [このレシピを編集する] → /recipes/edit/[id]        |
-----------------------------------------------------
```

---

# **5. 100レシピ自動生成ダッシュボード（/recipes/bulk）**

### 機能  
- 材料セット入力  
- Qwenで100レシピ生成  
- Jevで一括評価  
- ランキング表示  
- レーダーチャート比較

### モックアップ
```
-----------------------------------------------------
| 材料セット: [鶏肉, 玉ねぎ, 醤油, 砂糖]             |
| 条件: [和食 ▼] [バリエーション多め ▼]              |
-----------------------------------------------------
| [100レシピを自動生成する]                          |
-----------------------------------------------------
| バッチID: bulk_20260923_001                        |
| [味スコアを一括評価する（Jev）]                    |
-----------------------------------------------------
| ランキング表示                                     |
| -------------------------------------------------- |
| 総合得点ランキング                                 |
|   1位: レシピ501（72点）                           |
|   2位: レシピ502（70点）                           |
| 甘味ランキング                                     |
|   1位: レシピ502（60点）                           |
|   2位: レシピ501（40点）                           |
| ...                                                |
-----------------------------------------------------
| [レーダーチャートで比較する] → /recipes/compare    |
-----------------------------------------------------
```

---

# **6. レーダーチャート比較ページ（/recipes/compare）**

### 機能  
- 複数レシピの味覚スコアを重ね描画  
- 味の傾向を視覚的に比較

### モックアップ
```
-----------------------------------------------------
| 比較するレシピID: [101, 501, 502]                  |
| [チャートを表示]                                    |
-----------------------------------------------------
| レーダーチャート（重ね描画）                       |
|   - 101: 青                                         |
|   - 501: 赤                                         |
|   - 502: 緑                                         |
-----------------------------------------------------
| 味の傾向コメント（自動生成）                        |
|   ・レシピ501は旨味が強い                           |
|   ・レシピ502は甘味寄り                             |
|   ・レシピ101は辛味が高い                           |
-----------------------------------------------------
```
